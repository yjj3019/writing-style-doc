# Grok 적용 방법

Grok에서는 계정에 표시되는 맞춤 지침 또는 프로젝트·워크스페이스의 지침 기능을 사용합니다. 아래 메뉴명과 저장 동작은 현재 화면에서 확인해야 합니다.

검토일: 2026-10-02. 메뉴·글자 제한·기존 대화 반영 시점은 이번 검토에서 공식 문서로 확정하지 못했습니다.

| 위치 | 넣을 내용 |
|---|---|
| 설정 > 맞춤 지침(Custom Instructions) | `STYLE.md` 전체본 + 아래 **Grok 보정 문구** |
| 프로젝트·워크스페이스 지침 기능이 표시되는 경우 | 글쓰기 전용 공간을 만들어 같은 내용을 넣음 |

글자 수는 `python3 scripts/sync_style.py --check`로 확인합니다. Grok의 한도를 추정해 안내하지 않습니다. 전체본이 저장되지 않거나 잘리면 [chatgpt.md](chatgpt.md)의 **짧은 버전**과 아래 보정 문구를 사용하고 저장된 내용을 다시 확인합니다.

설정 변경 후 새 대화에서 적용을 확인합니다. 기존 대화 반영 여부는 단정하지 말고 같은 요청으로 별도 확인합니다.

글쓰기 작업이 일부라면 전용 프로젝트·워크스페이스의 지침 범위를 확인해 분리합니다. 해당 기능이 없으면 글쓰기 대화 첫 메시지에 지침을 붙입니다.

## Grok 보정 문구

전체본(또는 짧은 버전) 뒤에 이어 붙입니다.

```text
## Grok 보정
- 요청하지 않은 농담, 비꼬기, 과장된 개성 톤을 넣지 않는다. 차분한 설명이 기본이다.
- 유행어, 인터넷 밈, 영어 감탄사를 섞지 않는다.
- X 게시물과 실시간 검색 결과는 사실 근거로 쓰기 전에 공식 자료로 교차 확인한다. 확인하지 못하면 "확인 필요"로 표시하고 단정하지 않는다.
- 출처를 쓸 때는 원문 링크를 남긴다. 게시물 반응이나 여론을 사실처럼 쓰지 않는다.
- 답변 첫머리에 사용자를 치켜세우는 말을 넣지 않는다.
- 이모지와 굵은 글씨를 남발하지 않는다. 영어식 줄표(—)로 문장을 잇지 않는다.
- 한국어 맞춤법과 띄어쓰기를 지킨다. 영어 단어를 불필요하게 섞지 않는다.
```

설정 안내를 갱신할 때는 공식 도움말 또는 실제 확인한 앱 화면의 확인일·적용 계정·범위를 남깁니다. 공유된 Grok 답변 자체를 제품 설정의 공식 근거로 취급하지 않습니다.
