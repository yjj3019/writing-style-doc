# 전체·짧은 지침의 표·조건 보존 관찰

확인일: 2026-10-02. 전체 지침과 짧은 지침을 각각 두 독립 에이전트에 적용했다. 같은 [가상 입력](inputs/table-and-conditions.md)을 제공했고, 예상 답안이나 수정 목록은 전달하지 않았다. 실제 적용한 지침의 커밋·버전·SHA256과 정확한 입력·출력을 JSON에 기록했다. 모델·생성 설정은 도구 결과에 노출되지 않아 null과 사유를 남겼다.

| 지침 | 기록 | 관찰 |
|---|---|---|
| 전체 | [A](runs/20261002-full-table-a.json), [B](runs/20261002-full-table-b.json) | 제목·절·표·코드·인용·링크를 보존하고 문장을 다듬음 |
| 짧은 버전 | [A](runs/20261002-short-table-a.json), [B](runs/20261002-short-table-b.json) | 같은 구조를 유지하며 확인 가능·불가능 표현을 다듬음 |

네 출력의 제목과 절 순서, 두 표의 열·행·수치·상태, 코드 블록, 직접 인용, 링크 대상이 입력과 같음을 대조했다. 운영 미적용, 가상 시험 조건, 미시험, 원인 미확인, 시간 순서만으로 인과를 확정할 수 없다는 조건도 수동으로 확인했다. 전체 지침의 한 출력은 목적 문장을 바꿨고 두 출력은 운영팀의 변경 행위를 한 문장으로 합쳤으나, 이 입력에서 의미 손실은 발견하지 못했다.

사실·요청·가독성은 네 출력 모두 통과로 판단했다. 실제 사용자 글 샘플이 없어 개인 문체와 overall은 unassessed다. 구조 검사와 지침 해시 검증은 이 수동 의미 판단을 대신하지 않는다.

한 입력에서 각 지침을 두 번 관찰한 결과다. 실제 ChatGPT·Claude·Grok에 설치한 비교가 아니며, 장문 전반의 안정성이나 플랫폼 간 품질 동등성을 주장하지 않는다. 다음 문체 평가에는 실제 사용자에게서 제공받거나 사용이 허용된 익명화 글과 해당 식별자가 필요하다.
