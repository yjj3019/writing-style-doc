# 실제 문체 자료 등록

현재 등록된 실제 사용자 문체 자료는 없다. 가상 예시나 이전 대화의 개인 정보를 채워 넣지 않는다. 아래 형식을 사용자가 공개 가능한 본인 글을 제공했을 때만 작성한다.

| 항목 | 기록 내용 |
|---|---|
| 자료 식별자 | 개인 정보가 없는 짧은 이름 |
| 문서 종류·독자·목적 | 블로그 / 기술 안내 / 보고서 등 |
| 작성 주체·사용 범위 | 본인 글임을 확인하고 저장소 공개 가능 여부 기록 |
| 익명화 | 제거·치환한 정보의 종류만 기록. 원래 값이나 복원표 저장 금지 |
| 원문·완성 글 | 제공된 익명화 텍스트만. 모델이 대신 만든 글은 실제 자료로 표시하지 않음 |
| 사용자 선호 | 실제로 선택하거나 수정한 종결·전환·배치 |

처음에는 종류별로 1~3개면 충분하다. 일부 자료는 문체 참고용, 다른 자료는 평가용으로 분리해 같은 글을 보고 그대로 따라 쓴 결과를 재현 성능으로 계산하지 않는다. 개수를 채우기 위해 불필요한 자료를 공개하지 않는다.
