# 실제 문체 자료 적용 기준

사용자가 제공한 본인 글이 있을 때만 적용한다. 현재 저장소의 examples.md는 가상 편집 예시이며 실제 문체 자료가 아니다.

- 블로그·기술 안내·보고서를 구분하고 대상 글과 목적이 가까운 자료만 참고한다. 개인 블로그 말버릇을 업무 보고서에 강제로 넣지 않는다.
- 자료의 출처와 본인 작성 여부를 확인하고, 공개 배포용이라면 개인정보·내부 시스템·고객정보·비밀값을 먼저 제거한다. 공개해도 되는지 불명확한 글은 저장소에 넣지 않는다.
- 초안과 완성 글을 함께 받았다면 사용자가 실제로 고친 선택을 우선한다. 대화 기록이나 검색한 글을 본인 문체로 임의 채택하지 않는다.
- 종결·문장 호흡·전환·정보 배치만 참고한다. 샘플의 경험·수치·감정·주장을 새 글에 가져오지 않는다.
- 적용 자료가 없으면 공통 문체 기본값을 사용한다. 자료 부족 때문에 요청한 글쓰기를 중단하거나 경험을 만들지 않는다.
- 사용자 원문과 출력을 나란히 평가하되, 사실 보존·요청 준수·개인 문체·가독성을 별도로 판단한다. 익숙한 말버릇의 등장 횟수로 유사성을 판정하지 않는다.

공개 가능한 실제 자료를 추가하는 방법과 기록 형식은 저장소의 evaluation/style-samples.md를 참고한다. 설치된 스킬만 있다면 위 기준으로 사용자가 그 대화에 제공한 자료를 활용한다.
